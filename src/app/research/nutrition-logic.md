# 女子長距離選手向け 食事分析AI ロジック定義書

本ドキュメントは、正確な定量（g単位）ではなく、**食品群レベルでの半定量評価（Semi-quantitative assessment by food groups）** を行い、統計解析（ベイズ階層モデル等）に使用可能な順序尺度データ（Ordinal Data）を生成するためのAIロジックを定義します。

## 1. 分析の基本方針
*   **目的**: 鉄欠乏性貧血およびEnergy Availability (EA) 低下の**リスク因子の検出**。
*   **入力**: 食事の写真 または テキスト記述（メニュー名・量）。
*   **出力**: 栄養素量（mg/kcal）ではなく、**食品群別摂取レベルスコア (0〜3)**。
*   **統計的妥当性**: 
    *   連続値としての扱いは避け、順序変数（Ordered Categorical）として定義する。
    *   日次変動のノイズを許容し、週単位・月単位のトレンド解析に耐えうる構造とする。

## 2. 評価項目とスコアリング基準 (Scoring Criteria)

各項目は原則として `0` (None/Low) 〜 `3` (High/Optimal) の整数値で評価します。

### A. 鉄分供給源 (Iron Sources)

#### 1. ヘム鉄スコア (`hem_iron_score`)
赤身肉、魚（血合い部分）など、吸収率の高い鉄分の評価。
*   `0`: なし
*   `1`: 少量 (例: ひき肉少量、ハム数枚)
*   `2`: 中等量 (例: 1人前の魚、豚肉炒め)
*   `3`: 多量・高密度 (例: 牛ステーキ、レバー、カツオのたたき)

#### 2. 非ヘム鉄スコア (`non_hem_iron_score`)
大豆製品、緑黄色野菜、卵、海藻など。
*   `0`: なし
*   `1`: 副菜1品程度 (例: 冷奴のみ)
*   `2`: 複数品目あり (例: 納豆＋小松菜お浸し)
*   `3`: 充実している (例: 具沢山味噌汁＋副菜2品以上)

### B. 吸収調節因子 (Absorption Modulators)

#### 3. ビタミンC・酸スコア (`absorption_enhancer_score`)
鉄吸収を促進する食品群（果物、生野菜、酢・梅干し等）。
*   `0`: なし
*   `1`: 少量 (例: 付け合わせのキャベツ、ドレッシング)
*   `2`: 十分あり (例: 果物1個、サラダボウル、100%ジュース)

#### 4. 吸収阻害フラグ (`inhibitor_flag`)
食事中・食直後のタンニン（コーヒー、紅茶、緑茶）摂取。
*   `0`: なし (水、麦茶、ほうじ茶など)
*   `1`: あり (食事と一緒に緑茶・コーヒー等)
*   ※ 統計解析時は負の係数を想定したダミー変数として扱う。

### C. エネルギー可用性プロキシ (Energy Availability Proxy)

#### 5. 糖質可用性スコア (`carb_intake_score`)
練習によるグリコーゲン枯渇を補う主食量。
*   `0`: 不足 (主食抜き、極端に少ない)
*   `1`: やや少なめ (茶碗半分、パン1個)
*   `2`: 標準 (どんぶり飯、パスタ1人前)
*   `3`: 高炭水化物 (大盛り、主食重ね食べ ※リカバリー食)

## 3. 出力データ構造 (JSON Schema)

AIはこの構造でデータを返却し、データベースに保存します。

```json
{
  "analysis_summary": "夕食: ヘム鉄（牛）と非ヘム鉄（納豆）が両方含まれ、全体の鉄分量は良好です。食後のオレンジジュースも吸収を助けています。",
  "scores": {
    "hem_iron_score": 3,
    "non_hem_iron_score": 2,
    "absorption_enhancer_score": 2,
    "inhibitor_flag": 0,
    "carb_intake_score": 2
  },
  "tags": ["牛肉", "納豆", "オレンジジュース"],
  "reliability_level": "A" // A: 高確度 (写真あり), B: 中 (テキストのみ), C: 低 (情報不足)
}
```

## 4. 統計解析（ベイズ階層モデル）への適用イメージ

```r
# R / Stan pseudo-code
model {
  # フェリチン値の予測モデル
  ferritin[i] ~ Normal(mu[i], sigma)
  
  mu[i] = alpha[athlete_id[i]] + 
          beta1 * cumulative_hem_iron_score[i] +  # 累積ヘム鉄スコアの影響
          beta2 * cumulative_non_hem_iron_score[i] +
          beta3 * (absorption_enhancer_score[i] * iron_total[i]) + # 交互作用
          beta4 * inhibitor_flag[i]
}
```
このように、定量値でなくとも、スコアの累積値や平均値を共変量として用いることで、食事介入の効果測定が可能です。
